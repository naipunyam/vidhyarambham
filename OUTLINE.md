# Practical Entrepreneurship: From Idea to First Revenue — outline

Course id `entrepreneurship`, version 1, file `public/courses/entrepreneurship.json`.
Paces: Part-time (weekLength 1, ~6 h/week, 32 weeks) and Full-time (weekLength 0.25, ~24 h/week, ~8 weeks).
Week 0 = setup. totalWeeks = 32.

Running examples (fictional, one per path):
- Nisha's Oven — home bakery, Kuttiady (local business; FSSAI)
- Arun's ShopAssist — WhatsApp Business + Google profile setup for shops, Vatakara (freelance → agency)
- PSC Sprint — original Kerala PSC practice packs + mock tests (digital product)
- Meera's CV Makeover — fixed-price CV + LinkedIn rewrite for Gulf job seekers (online service)
